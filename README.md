# socket_vmnet sliding-queue fork

This fork develops a non-blocking client flood path and native datagram support on top of
[`lima-vm/socket_vmnet`](https://github.com/lima-vm/socket_vmnet).

The original project documentation is preserved in [README.upstream.md](README.upstream.md).
Usage, tuning, diagnostics, measurements, and attribution for the fork are documented here as the
corresponding changes are introduced.
